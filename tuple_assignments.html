19. Add an item from the user

Start with t = (10, 20, 30).
Part A: ask the user for a number, add it to the end of the tuple using +, and print the new tuple.
Part B: start again from the original tuple and do the same using list(), append() and tuple().

Sample output
Enter a number: 40
(10, 20, 30, 40)
Enter a number: 50
(10, 20, 30, 50)
t = (10, 20, 30)

# Part A
n = int(input("Enter a number: "))
t = t + (n,)
print(t)

# Part B
t = (10, 20, 30)
temp = list(t)
n = int(input("Enter a number: "))
temp.append(n)
t = tuple(temp)
print(t)

20. Student record

Ask the user for a name and marks in 3 subjects (numbers). Store all four values in a tuple named record. Print the record, the total marks and the average. Use indexing to get the marks from the tuple.

Sample output

('Riya', 80, 70, 90)
